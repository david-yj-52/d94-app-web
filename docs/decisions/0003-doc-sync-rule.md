# ADR 0003: 코드-문서 동기화 규칙과 자동 검사

- 상태: 채택
- 날짜: 2026-10-15
- 관련: [ADR 0002](0002-layered-context-docs.md)

## 배경
4계층 컨텍스트 문서(AGENTS.md 28개)는 코드와 일치할 때만 가치가 있습니다. 개발이 진행되면서 문서 갱신을 빠뜨리면, AI 도구가 낡은 props, 경로, 구조를 근거로 코드를 작성하게 됩니다.

## 결정
1. **L1 규칙:** `AGENTS.md` §10에 다음을 둡니다.
   - 문서 갱신은 코드 변경과 같은 작업·커밋에 기본으로 포함됩니다.
   - "변경 유형 → 갱신할 문서" 매핑표를 따릅니다.
   - 작업 마무리 절차를 지킵니다. 모든 AI 도구가 L1을 항상 읽으므로 도구와 상관없이 적용됩니다.
2. **자동 검사:** `npm run docs:check`(`scripts/check-docs.mjs`, 의존성 없음)
   - **오류(exit 1):** 기계적으로 판별할 수 있는 불일치입니다. 링크, AGENTS/CLAUDE 짝, §0 지도, 컴포넌트 카탈로그, 훅 표, 화면별 L3 문서, 문서에 적힌 `@/…` import 경로를 검사합니다.
   - **경고:** `git diff` 기준으로 바뀐 코드 파일의 가장 가까운 `AGENTS.md`가 바뀌지 않았으면 알립니다. 그 컴포넌트나 훅을 쓰는 화면의 L3 문서도 "영향 가능"으로 알립니다.
3. **훅(pre-commit, Claude Code Stop hook)은 도입하지 않습니다.** 연습장 특성상 커밋이 막히는 비용이 크다고 판단했습니다. 규칙과 수동 실행으로 시작하고, 누락이 반복되면 다시 검토합니다.

## 결과
- props 내용이나 기능 설명이 정확한지는 스크립트가 판별하지 못합니다. 경고를 단서로 사람이나 AI가 확인해야 합니다.
- 문서 구조를 바꿀 때는 `scripts/check-docs.mjs`의 검사 기준도 함께 고쳐야 합니다. 예를 들어 §0 지도 형식이 바뀌면 지도 검사 로직을 맞춰야 합니다.
